# 确认互证说明（当日锁死）

> 生效日期：2026-11-21
> 范围：档期预订确认链路（占位 → 正式册 → 互证册）
> 状态：**钉死，禁止漂移**

## 1. 事故口径

确认接口返回成功、正式册 `bookings` 有行，但互证页空（无互证记录），前台误以为没订上。
根因：确认服务未把互证写入与正式册写入放进**同一事务**，出现假绿分裂。

## 2. 钉死路径：甲路径——同事务双写

本仓只允许甲路径，乙路径（互证草稿 → 原子落正式与已签发）**禁止启用**，两边不得混用。

同一数据库事务、同一连接内按序完成，任一失败整体回滚：

1. 抢档锁 `slot:{code}`（两人同时确认同一占位，后到只记 `contention_log` 争用痕，不进业务）；
2. 持锁复检占位态（必须「占位中」、未过期、容量够）；
3. 写正式册 `bookings`（状态「已确认」）；
4. 写互证册 `attestations`（状态只允许「已签发」，与正式册 1:1，携带 `proof_code`、`snapshot_gen`）；
5. 翻占位态 `holds.status='已确认'`、增档期盘 `slots.booked`；
6. 写审计 `booking_confirm`（带 `proof_code`）；
7. 提交事务并释放档锁。

**失败语义（甲路径）：** 第 3–6 步任一步抛错 → `rollback` → 正式零增、互证零增、占位态不翻转、档期盘不增、锁必释放。
**禁止只返回成功文案**：成功响应必须带 `proof_code` 与 `booking_id`。

## 3. 偏航护栏

- 互证册 `attestations.status` 只接受 `已签发`（见 `db.ATTESTATION_ALLOWED_STATUSES`）。
- 出现 `草稿` / `已作废` 等乙路径残留态 → `AttestationDriftError`：
  - 业务事务回滚（正式零增、互证零增）；
  - 另起事务写审计 `确认互证偏航`（`db.ATTESTATION_DRIFT_ACTION`）；
  - 接口返回 409，拒绝确认。
- 护栏有测试钉住：`tests/test_confirm_attestation.py::test_draft_attestation_is_drift_rejected`。

## 4. 五处同态

一次成功确认后，下列五处必须同态，由
`tests/test_confirm_attestation.py::test_five_views_stay_homomorphic_after_confirm` 守住：

| # | 位置 | 表/接口 | 同态要求 |
|---|------|---------|----------|
| 1 | 正式册 | `bookings` | 新增 1 行「已确认」 |
| 2 | 互证页 | `attestations` / `GET /api/proof/{party_key}` | 新增 1 行「已签发」，`attestation_ok=true` |
| 3 | 占位态 | `holds` | 该行翻为「已确认」，占位中数 −1 |
| 4 | 对账 | `GET /api/reconcile` | 盘面 booked = 正式册席 = 互证册席，三方相等 |
| 5 | 审计 | `audit_trail` | `booking_confirm` +1，负载带 `proof_code` |

存量老库在 `init_db()` 内通过 `backfill_attestations` 对历史已确认正式册补签互证
（`proof_code=PF-BACKFILL-*`，并留 `attestation_backfill` 审计），不替换库文件、不留假绿。
回填幂等：已存在互证的正式册不会重复补签（LEFT JOIN 判空），重复启动安全。
应用启动（容器内 root）即自动完成建表与回填；当前沙箱 `data/app.db` 为 root 只读，
本地非 root 无法原地写，已在该库的可写副本上验证升级与幂等性。

## 5. 假绿夹具

`fixtures/false_green_no_attestation.json` 固化「确认成功却互证空」的分裂态，
由 `test_false_green_booking_without_attestation_is_flagged` 验证：
互证页 `attestation_ok=false`、对账 `ok=false`，分裂必须显形而不是空页假绿。

## 6. 争用语义

两人同时确认同一占位：档锁先到先得；后到者只在 `contention_log` 留争用痕，
正式册/互证册/占位态/档期盘/业务审计零增。持锁者完成后，后到者的二次确认由
持锁复检的状态护栏以 409 拒绝，互证不重复签发（`attestations.booking_id UNIQUE`）。
